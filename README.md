# Who web demo

[Open the site](https://shubin123.github.io/desert-ant-who-demo/)

Speaker labeling with per-person turns and timestamps.

**Status: access/integration page, not functional inference.** The public release currently provides compiled Apple CoreML models, without a browser-ready runtime or a complete public inference pipeline. This page does not perform speaker labeling.

Powered by [Desert Ant Labs](https://desertant.com) 🐜. See [ATTRIBUTION.md](ATTRIBUTION.md). Model ownership remains with Desert Ant Labs B.V.

## Run locally

Serve with python3 -m http.server 8080 --directory site and open http://localhost:8080. The included workflow publishes to GitHub Pages. The canonical SVG icon matches Shubin123/portfolio in both the favicon and site header.
